# Party Web Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** ย้ายระบบปาร์ตี้หารค่าใช้จ่ายมาอยู่บนเว็บทั้งหมด (สมาชิก = บัญชีเว็บ) และลบบอท Discord

**Architecture:** SQL functions atomic ใน Supabase (เขียนใหม่ด้วย uuid ของบัญชีเว็บ) → `party_store.PartyStore` → FastAPI `/api/parties/...` (ตรวจ login/สมาชิกที่ server) → หน้า HTML/JS `/parties`, `/party/<id>`, `/join/<code>`; ใช้ `party_math`, `/api/slips/read`, `current_user` เดิม

**Tech Stack:** Python 3.12, FastAPI, httpx, Supabase Postgres/PostgREST, HTML/JS (supabase-js), pytest

**Spec:** `docs/superpowers/specs/2026-10-29-party-web-design.md`

## Global Constraints

- branch `party-group`; ห้ามเปลี่ยนพฤติกรรม `/api/expenses`, `/api/summary`, dashboard รายจ่ายส่วนตัว (เพิ่มได้: ลิงก์ "ปาร์ตี้", ฟิลด์ `image_sha256` ใน `/api/slips/read`)
- เทสต์ทั้งหมด `.venv/Scripts/python.exe -m pytest -q` ผ่านทุก task
- เงิน = สตางค์ int; ยอดจาก client เป็นสตริง → `party_math.parse_baht`
- ≤ 10 คน (`MAX_MEMBERS`), โค้ด 6 ตัวจาก `ABCDEFGHJKMNPQRSTUVWXYZ23456789`, สถานะ `open`/`closed`/`settled`
- ไม่ใช่สมาชิกปาร์ตี้ → 404 เสมอ (ไม่บอกว่ามีอยู่)
- ข้อความผู้ใช้ภาษาไทย; สไตล์โค้ดเดิม; commit ลงท้าย `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`
- ทดสอบที่ต้องใช้ DB จริง / browser เลื่อนไปตอนจบ (เจ้าของสั่ง: รัน SQL ตอนจบทีเดียว)
