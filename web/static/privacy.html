นโยบายความเป็นส่วนตัว

ปรับปรุงล่าสุด 30 ตุลาคม 2569 (2026)

ข้อมูลที่เราเก็บ

  • จากการเข้าสู่ระบบ (Discord, Google หรืออีเมล): อีเมล ชื่อที่แสดง และรหัสบัญชีของผู้ให้บริการ login
  • รายการค่าใช้จ่ายที่คุณบันทึก: ยอดเงิน วันที่ เวลา ผู้รับ หมวด หมายเหตุ ธนาคาร และเลขอ้างอิงของสลิป
  • ข้อมูลปาร์ตี้: ชื่อปาร์ตี้ สมาชิก (ชื่อที่แสดง) รายการที่หารกัน รายการโอน และค่าตรวจสอบสลิป (เลขอ้างอิงและค่า hash ของรูป) เพื่อกันสลิปซ้ำ

รูปสลิป

รูปสลิปที่อัปโหลดถูกส่งไปยังบริการอ่านข้อความภายนอก คือ Gemini API (Google) และ/หรือ Typhoon API เพื่ออ่านยอดเงิน วันที่ และผู้รับ — เว็บนี้ไม่เก็บไฟล์รูป เก็บเฉพาะข้อมูลที่อ่านได้และคุณยืนยันแล้ว

เว็บนี้ใช้ Gemini API แบบไม่เสียค่าใช้จ่าย ซึ่ง Google อาจนำข้อมูลที่ส่งไปใช้ปรับปรุงผลิตภัณฑ์ของ Google — หากไม่ต้องการ โปรดกรอกยอดเองแทนการอัปโหลดรูป

ใครเห็นข้อมูลของคุณ

  • รายจ่ายส่วนตัว: เห็นเฉพาะคุณ
  • ปาร์ตี้: สมาชิกในปาร์ตี้เดียวกันเห็นชื่อที่แสดงและทุกรายการในปาร์ตี้นั้น
  • ข้อมูลเก็บใน Supabase (ฐานข้อมูล) และเว็บรันบน Render — เราไม่ขาย ไม่ให้เช่า และไม่ใช้ข้อมูลเพื่อโฆษณา
  • สถานะการเข้าสู่ระบบเก็บไว้ในเบราว์เซอร์ของคุณ (local storage) ไม่มีคุกกี้โฆษณาหรือตัวติดตาม

การลบข้อมูล

ลบรายการค่าใช้จ่ายของคุณได้เองในหน้ารายจ่าย หากต้องการลบบัญชีและข้อมูลทั้งหมด แจ้งได้ที่ GitHub ของโปรเจกต์
